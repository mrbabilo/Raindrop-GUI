# Réglages — Plan d'implémentation (spéc §6)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un écran de Réglages (⌘, + engrenage) qui montre l'état de la
connexion, permet de remplacer le jeton sans repasser par le premier
lancement, et de se déconnecter.

**Architecture:** Overlay à l'idiome de la Palette (⌘K), ouvert par ⌘,
et un engrenage dans l'en-tête à côté du thème. L'état MCP vient du
`useHealth` existant (queryKey partagé, zéro requête nouvelle). Le
remplacement de jeton rejoue `enregistrer_jeton` (trousseau → sidecar →
attente MCP connecté — tout existe). La déconnexion est une NOUVELLE
commande Rust `deconnecter` : `trousseau::effacer()` + arrêt du sidecar +
`JetonRequis` — `effacer()` obtient enfin son appelant.

**Tech Stack:** Rust (tauri 2), React 18 + vitest, i18n `fr.ts`.

**Spec:** `docs/superpowers/specs/2026-09-15-raindrop-gui-design.md` §6
(« Réglages : remplacer le token, état de la connexion MCP, préférences
d'affichage »).

### Task 2: La commande `deconnecter`

**Files:**
- Modify: `src-tauri/src/commandes.rs`
- Modify: `src-tauri/src/lib.rs` (generate_handler)

**Interfaces:**
- Produces: commande `deconnecter(app: AppHandle) -> EtatConnexion` —
  `trousseau::effacer()` ; `etat.arreter_sidecar(GRACE)` ; efface le
  lockfile (l'app peut mourir avant que le sidecar ait fini son propre
  ménage) ; `etat.poser(JetonRequis.clone())` ; rend `JetonRequis`.
  Erreur d'effacement → `Panne { detail }` (le sidecar continue de tourner,
  l'utilisateur peut Réessayer).

- [ ] **Step 1: Commande** (forme identique aux autres : `async fn` +
  `spawn_blocking`, AppHandle, `app.state::<Etat>()` DANS la closure) :

```rust
/// Déconnexion (spec §6, réglages) : efface le jeton du trousseau et
/// arrête le sidecar — l'écran de premier lancement reprend la main.
/// L'effacement AVANT l'arrêt : si l'app meurt entre les deux, aucun
/// sidecar ne tourne avec un jeton que le trousseau a oublié.
#[tauri::command]
pub async fn deconnecter(app: AppHandle) -> EtatConnexion {
    tauri::async_runtime::spawn_blocking(move || {
        let etat = app.state::<Etat>();
        if let Err(detail) = trousseau::effacer() {
            return EtatConnexion::Panne { detail };
        }
        etat.arreter_sidecar(commandes_grace());
        let _ = std::fs::remove_file(verrou::chemin(&etat.dossier));
        let e = EtatConnexion::JetonRequis;
        etat.poser(e.clone());
        e
    })
    .await
    .unwrap_or_else(|e| EtatConnexion::Panne {
        detail: format!("déconnexion interrompue : {e}"),
    })
}
```

(`commandes_grace()` : exposer `GRACE` de commandes.rs en `pub(crate) fn`
ou re-exporter la constante — au plus simple qui compile.)
- [ ] **Step 2:** `cargo build` + `cargo test` (60/2 inchangé — la commande
  est fine, le front la teste par mock).
- [ ] **Step 3:** `lib.rs` generate_handler + Commit
  `feat(tauri): déconnexion — efface le jeton et arrête le sidecar`.
