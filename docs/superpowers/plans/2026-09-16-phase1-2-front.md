# Raindrop-GUI Phase 1 — Plan 2/3 : Front React (bibliothèque + nettoyage)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** Front React consommant l'API REST réelle du sidecar (livré, plan 1) : bibliothèque à trois panneaux virtualisée avec ⌘K et composer, vues de nettoyage (dashboard, liens morts, redirections, doublons, non-taggés, collections vides, corbeille), et page « Revue de l'action » à deux niveaux — le tout en français, clair/sombre, testé en Vitest/Testing Library.

**Architecture :** SPA à un écran (pas de router) : un store `useReducer` porte la vue courante et la sélection ; TanStack Query porte les données serveur (collections, tags, raindrops paginés, analyse) ; un client fetch typé (`lib/api.ts`) est la SEULE porte vers le sidecar ; les jobs SSE passent par un fetch-stream manuel (EventSource ne peut pas poser d'Authorization). En dev, le proxy Vite lit le port du sidecar dans son lockfile ; en prod (plan 3), Tauri injecte `window.RAINDROP_GUI = {port, token}` avant le chargement.

**Tech Stack :** React 18, TypeScript 5 strict (moduleResolution `bundler` — imports SANS extension côté front), Vite 7, Tailwind 4 (@tailwindcss/vite), TanStack Query 5, TanStack Virtual 3, Vitest + Testing Library + jsdom.

**Spec :** `docs/superpowers/specs/2026-09-15-raindrop-gui-design.md` (§4 Interface, §7 États dégradés, §8 Tests) — le plan argue de la spec, exécuteurs lisez les deux.

## Global Constraints

- **Le front ne connaît QUE l'API REST locale** — aucun code MCP, aucun import du sidecar.
- **Connexion** : `window.RAINDROP_GUI = {port: number, token: string}` injecté par Tauri en prod ; sinon dev = même origine (proxy Vite vers le port du lockfile) + `VITE_LOCAL_API_TOKEN`. Le token ne transite JAMAIS ailleurs.
- **API réelle** (sidecar livré) : `GET /api/raindrops` (query `collection_id, search, sort, page, per_page≤50, important, notag, domain, media, created_start, created_end` — `important`/`notag` valent `"true"`/`"false"` ou sont absents) → `{items: RaindropItem[], count, page, perPage}` ; `GET /api/collections` → `{items: Collection[]}` (root+children fusionnés) ; `GET /api/tags` → `{items: {name, count}[]}` ; `GET /api/user` ; `GET /api/highlights/:raindropId` → **forme brute** `{items: [{_id, text, note, color, created}]}` (mapper `_id`→`id` côté front) ; `POST/PATCH/DELETE /api/raindrops[/:id]` (**`DELETE /api/raindrops/:id?from=<collectionId>`** — `from` = collection courante, mémorisée pour la restauration, Task 0b) ; `POST /api/raindrops/unrestore {ids, toCollectionId?}` → `{restored, unknown: number[]}` ; `POST /api/raindrops/bulk {operation, collection_id, ids?, to_collection_id?, tags?, important?}` (move exige ids+to_collection_id ; delete exige ids ; update exige tags ou important) ; `POST /api/tags/manage {operation, tags, new_name?, collection_id?}` (rename/merge exigent new_name) ; `POST /api/collections/cleanup {confirm}` ; `POST /api/maintenance/empty-trash {confirm: true}` ; `POST /api/parse-url {url}` ; `POST /api/check-urls {urls}` ; `POST /api/analysis/scan {type: "links"|"duplicates"}` → 202 `{jobId}` ; `GET /api/analysis/status` ; `GET /api/analysis/results/links?page&per_page&filter` ; `GET /api/analysis/results/duplicates` ; `GET /api/jobs/:id` ; `GET /api/jobs/:id/events` (SSE : `progress`/`done`/`error`/`cancelled` + `ping` — **`done` porte le result nu, les autres l'enveloppe**) ; `POST /api/jobs/:id/cancel` ; `GET /api/health` → `{status, mcp}` ; `POST /api/mcp/restart`.
- **Erreurs uniformes** `{error: {code, message, tool?}}` — codes MCP_TIMEOUT/MCP_CRASHED/RATE_LIMITED/RAINDROP_API/INVALID_INPUT ; 401 (token) et 403 (Origin) portent aussi INVALID_INPUT. Traitement front **par code + statut**.
- **Identifiants** : Tous = `0`, non classés = `-1`, corbeille = `-99`. Non-lus = `search: "status:unread"`.

### Task 0b : Sidecar — corriger `unrestore` + mémoire des origines de corbeille

Corrige la Task 0. L'API ne propose **que** `PUT /raindrops/-99 {ids, collection:{"$id": N}}`,
qui impose une destination, et la corbeille **ne conserve pas** la collection d'origine
(`collectionId` → `-99`, `removed` → `true` — vérifié). D'où la décision spec §4.2
(restauration hybride) : le sidecar note l'origine quand c'est **lui** qui met à la
corbeille ; sinon le front demandera la destination.

**Files:**
- Modify: `sidecar/direct/raindropRest.ts` (`unrestore(ids, toCollectionId)` → `PUT /raindrops/-99`)
- Create: `sidecar/trash/origins.ts` (mémoire `{id → collectionId}`, persistée en app-data)
- Modify: `sidecar/api/routes/raindrops.ts` (`DELETE /:id?from=`, `POST /bulk` operation delete → mémorise, nouveau contrat `POST /unrestore`)
- Modify: `sidecar/api/deps.ts` (`direct.unrestore` resignée, `deps.origins`)
- Modify: `sidecar/index.ts` (câblage du store)
- Test: `sidecar/direct/raindropRest.test.ts`, `sidecar/trash/origins.test.ts`, `sidecar/api/routes/raindrops.test.ts`

**Interfaces:**
- Produces : `DELETE /api/raindrops/:id?from=<collectionId>` — `from` optionnel ; fourni, il mémorise l'origine avant suppression.
- Produces : `POST /api/raindrops/unrestore {ids: number[], toCollectionId?: number}` → `{restored: number, unknown: number[]}`. Avec `toCollectionId`, tout part là. Sans, regroupement par origine mémorisée ; les ids sans origine connue reviennent dans `unknown` **sans être restaurés**.
- Consumes : `makeRestClient`, `deps.direct`, `cfg` (chemin app-data).

- [ ] **Step 1: REST direct (RED puis GREEN)**

`raindropRest.test.ts` — remplacer le test de la Task 0. Assertions contraignantes :
méthode `PUT`, URL `https://api.raindrop.io/rest/v1/raindrops/-99`, corps
`{ids: [7,9], collection: {"$id": 42}}`, Bearer présent (la Task 0 ne l'assertait pas —
minor relevé au ledger, corrigé ici).

Signature : `unrestore(ids: number[], toCollectionId: number): Promise<CallOutcome<{restored: number}>>`.
La destination n'est plus optionnelle **à ce niveau** : c'est la route qui résout l'origine.

- [ ] **Step 2: Store des origines (TDD)**

`sidecar/trash/origins.ts` — `makeOriginStore({file})` : `remember(id, collectionId)`,
`take(ids) → {known: Map<number, number>, unknown: number[]}`, `forget(ids)`.
Persistance JSON (même patron que `sidecar/analysis/cache.ts` — **le relire et le suivre**,
y compris sa file d'écriture sérialisée : le flake du logger venait de writes concurrents).
Jamais une source de vérité (§11) : un fichier absent ou illisible = toutes origines inconnues,
jamais une erreur remontée à l'appelant.

- [ ] **Step 3: Routes**

`DELETE /:id` — lire `from` (`z.coerce.number().int().optional()` ; ⚠️ pas de
`z.coerce.boolean()`, cf. ruling R10). Si présent, `origins.remember(id, from)` **avant**
`delete_raindrop` ; l'échec du store ne fait pas échouer la suppression.

`POST /bulk` avec `operation: "delete"` — **même mémorisation** : `origins.remember(id, collection_id)`
pour chaque id, la source étant le `collection_id` de la requête. ⚠️ Sans cela, tout ce qui part
à la corbeille en masse (BulkBar Task 9, ReviewPage Task 15 — le cas **courant** d'un nettoyage)
reviendrait en `unknown` et forcerait la demande de destination : la décision §4.2 serait vidée
de son sens là où elle sert le plus.

`POST /unrestore` — corps `{ids, toCollectionId?}`. Avec `toCollectionId` : un seul appel
`direct.unrestore(ids, toCollectionId)`. Sans : `origins.take(ids)`, un appel **par collection
de destination** (le throttle 550 ms les espace), `unknown` renvoyé tel quel.

⚠️ `take` est une **lecture pure** — il ne retire rien. Seul `origins.forget` écrit, et
**uniquement sur les ids d'un groupe effectivement restauré** : si une destination réussit et
une autre échoue, les origines du groupe en échec doivent survivre, sinon ces éléments
deviennent irrécupérables à l'origine au prochain essai.

```ts
export type ThemeMode = "system" | "light" | "dark";
const KEY = "raindrop-gui-theme";

export function initTheme(): ThemeMode {
  const mode = (localStorage.getItem(KEY) as ThemeMode) ?? "system";
  apply(mode);
  return mode;
}

export function setTheme(mode: ThemeMode): void {
  localStorage.setItem(KEY, mode);
  apply(mode);
}

function apply(mode: ThemeMode): void {
  const dark = mode === "dark" || (mode === "system" && matchMedia("(prefers-color-scheme: dark)").matches);
  document.documentElement.classList.toggle("dark", dark);
}
```

```ts
import { getConnection } from "./connection";
import type { ErrorCode } from "../../shared/errors";

export class ApiError extends Error {
  constructor(public code: ErrorCode, public status: number, message: string) {
    super(message);
  }
}

type Query = Record<string, string | number | boolean | undefined>;

function qs(query?: Query): string {
  const p = new URLSearchParams();
  for (const [k, v] of Object.entries(query ?? {})) if (v !== undefined) p.set(k, String(v));
  const s = p.toString();
  return s ? `?${s}` : "";
}

async function request<T>(method: string, path: string, body?: unknown): Promise<T> {
  const { baseUrl, token } = getConnection();
  const res = await fetch(`${baseUrl}${path}`, {
    method,
    headers: {
      Authorization: `Bearer ${token}`,
      ...(body !== undefined ? { "Content-Type": "application/json" } : {}),
    },
    body: body !== undefined ? JSON.stringify(body) : undefined,
    signal: AbortSignal.timeout(70_000), // pire-cas lecture MCP : 2×timeout + retry 2 s (contrainte plan 2)
  });
  if (!res.ok) {
    let code: ErrorCode = "RAINDROP_API";
    let message = `http ${res.status}`;
    try {
      const j = (await res.json()) as { error?: { code?: ErrorCode; message?: string } };
      if (j.error?.code) code = j.error.code;
      if (j.error?.message) message = j.error.message;
    } catch { /* corps non JSON */ }
    throw new ApiError(code, res.status, message);
  }
  return (await res.json()) as T;
}

export const api = {
  get: <T>(path: string, query?: Query) => request<T>("GET", path + qs(query)),
  send: <T>(method: "POST" | "PATCH" | "DELETE", path: string, body?: unknown) => request<T>(method, path, body),
};
```

```ts
import { useInfiniteQuery } from "@tanstack/react-query";
import { api } from "../lib/api";
import type { RaindropItem, Paginated } from "../../shared/types";

export interface RaindropQuery {
  collectionId: number;
  search?: string; sort?: string; important?: boolean; notag?: boolean;
  domain?: string; media?: string; createdStart?: string; createdEnd?: string;
}

const bool = (v?: boolean) => (v === undefined ? undefined : v ? "true" : "false");

export function useRaindrops(q: RaindropQuery) {
  return useInfiniteQuery({
    queryKey: ["raindrops", q],
    queryFn: ({ pageParam }) =>
      api.get<Paginated<RaindropItem>>("/api/raindrops", {
        collection_id: q.collectionId,
        search: q.search ?? (q.collectionId === -2 ? "status:unread" : undefined), // -2 = vue Non-lus (convention front)
        sort: q.sort,
        important: bool(q.important),
        notag: bool(q.notag),
        domain: q.domain,
        media: q.media,
        created_start: q.createdStart,
        created_end: q.createdEnd,
        per_page: 50,
        page: pageParam,
      }),
    initialPageParam: 0,
    getNextPageParam: (last, all) =>
      all.reduce((n, p) => n + p.items.length, 0) < last.count ? all.length : undefined,
  });
}
```

```tsx
  | { kind: "tags" };

interface State { view: View }
type Action = { type: "go"; view: View };

const initial: State = { view: { kind: "list", collectionId: 0, label: "Tous" } };
function reducer(s: State, a: Action): State { return a.type === "go" ? { view: a.view } : s; }

const Ctx = createContext<{ view: View; go: (v: View) => void }>({ view: initial.view, go: () => undefined });

export function AppStateProvider({ children }: { children: ReactNode }) {
  const [state, dispatch] = useReducer(reducer, initial);
  return <Ctx.Provider value={{ view: state.view, go: (view) => dispatch({ type: "go", view }) }}>{children}</Ctx.Provider>;
}

export const useAppState = () => useContext(Ctx);
```

```tsx
  const virtual = useVirtualizer({ count: items.length, getScrollElement: () => parentRef.current, estimateSize: () => 76, overscan: 10 });

  if (items.length === 0 && !query.isFetching) return <main className="grid place-items-center p-4 text-app-muted">{t("state.empty")}</main>;

  return (
    <main ref={parentRef} className="overflow-y-auto">
      {view.viewMode === "mosaic" ? (
        <div className="grid grid-cols-[repeat(auto-fill,minmax(160px,1fr))] gap-2 p-2">
          {items.map((r) => <MosaicTile key={r.id} r={r} onOpen={() => selectRaindrop(r.id)} />)}
        </div>
      ) : (
        <div style={{ height: virtual.getTotalSize(), position: "relative" }}>
          {virtual.getVirtualItems().map((v) => {
            const r = items[v.index]!;
            return (
              <div key={r.id} style={{ position: "absolute", top: 0, left: 0, width: "100%", transform: `translateY(${v.start}px)` }}>
                <RaindropRow r={r} selected={selectedIds.has(r.id)} isDetail={selectedRaindropId === r.id}
                  onOpen={() => selectRaindrop(r.id)} onToggle={() => toggleSelect(r.id)} onTag={(name) => patchList({ search: `#${name}` })} />
              </div>
            );
          })}
        </div>
      )}
      {query.hasNextPage && (
        <div ref={(el) => {
          if (!el) return;
          const io = new IntersectionObserver((es) => es.forEach((e) => e.isIntersecting && query.fetchNextPage()));
          io.observe(el);
        }} className="p-4 text-center text-app-muted">{query.isFetchingNextPage ? "…" : ""}</div>
      )}
    </main>
  );
}
```

```ts
import { useMutation, useQueryClient } from "@tanstack/react-query";
import { api } from "../lib/api";
import type { RaindropItem } from "../../shared/types";

export function useInvalidate() {
  const qc = useQueryClient();
  return (...keys: string[]) => keys.forEach((k) => void qc.invalidateQueries({ queryKey: [k] }));
}

export const useUpdateRaindrop = (id: number) => {
  const invalidate = useInvalidate();
  return useMutation({
    mutationFn: (patch: Partial<Pick<RaindropItem, "title" | "excerpt" | "note" | "tags" | "important" | "collectionId">>) =>
      api.send<RaindropItem>("PATCH", `/api/raindrops/${id}`, {
        ...patch, ...(patch.collectionId !== undefined ? { collection_id: patch.collectionId } : {}),
      }),
    onSuccess: () => invalidate("raindrops", "collections"),
  });
};

export const useTrashRaindrop = () => {
  const invalidate = useInvalidate();
  return useMutation({
    // `from` = collection courante de l'item : le sidecar la mémorise pour
    // pouvoir restaurer à l'origine (spec §4.2, Task 0b). Omis = origine inconnue.
    mutationFn: (v: { id: number; from?: number }) =>
      api.send("DELETE", `/api/raindrops/${v.id}${v.from != null ? `?from=${v.from}` : ""}`),
    onSuccess: () => invalidate("raindrops", "collections", "tags"),
  });
};

export const useCreateRaindrop = () => {
  const invalidate = useInvalidate();
  return useMutation({
    mutationFn: (body: { link: string; title?: string; excerpt?: string; collection_id?: number }) =>
      api.send<RaindropItem>("POST", "/api/raindrops", body),
    onSuccess: () => invalidate("raindrops", "collections"),
  });
};

export const useBulk = () => {
  const invalidate = useInvalidate();
  return useMutation({
    mutationFn: (body: { operation: "update" | "move" | "delete"; collection_id: number; ids?: number[]; to_collection_id?: number; tags?: string[]; important?: boolean }) =>
      api.send("POST", "/api/raindrops/bulk", body),
    onSuccess: () => invalidate("raindrops", "collections", "tags"),
  });
};

export const useTagManage = () => {
  const invalidate = useInvalidate();
  return useMutation({
    mutationFn: (body: { operation: "rename" | "merge" | "delete"; tags: string[]; new_name?: string }) =>
      api.send("POST", "/api/tags/manage", body),
    onSuccess: () => invalidate("tags", "raindrops"),
  });
};

export const useUnrestore = () => {
  const invalidate = useInvalidate();
  return useMutation({
    // Sans toCollectionId, le sidecar restaure chacun à son origine mémorisée et
    // renvoie dans `unknown` ceux dont l'origine est inconnue — NON restaurés :
    // l'appelant demande alors une destination et rappelle (spec §4.2).
    mutationFn: (v: { ids: number[]; toCollectionId?: number }) =>
      api.send<{ restored: number; unknown: number[] }>("POST", "/api/raindrops/unrestore", v),
    onSuccess: () => invalidate("raindrops", "collections", "tags"),
  });
};

export const useEmptyTrash = () => {
  const invalidate = useInvalidate();
  return useMutation({
    mutationFn: () => api.send("POST", "/api/maintenance/empty-trash", { confirm: true }),
    onSuccess: () => invalidate("raindrops"),
  });
};

export const useCleanupCollections = () => {
  const invalidate = useInvalidate();
  return useMutation({
    mutationFn: (confirm: boolean) => api.send("POST", "/api/collections/cleanup", { confirm }),
    onSuccess: () => invalidate("collections"),
  });
};

export const useDeleteCollection = () => {
  const invalidate = useInvalidate();
  return useMutation({
    mutationFn: (id: number) => api.send("DELETE", `/api/collections/${id}`),
    onSuccess: () => invalidate("collections"),
  });
};
```

```ts
import { getConnection } from "./connection";

export async function jobEvents(
  jobId: string,
  handlers: { onEvent(evt: { kind: string; [k: string]: unknown }): void; onDone(): void },
  signal: AbortSignal,
): Promise<void> {
  const { baseUrl, token } = getConnection();
  const res = await fetch(`${baseUrl}/api/jobs/${jobId}/events`, { headers: { Authorization: `Bearer ${token}` }, signal });
  const reader = res.body!.getReader();
  const decoder = new TextDecoder();
  let buffer = "";
  const handle = (block: string) => {
    const eventLine = block.split("\n").find((l) => l.startsWith("event: "));
    const dataLine = block.split("\n").find((l) => l.startsWith("data: "));
    if (!eventLine) return;
    const kind = eventLine.slice(7).trim();
    if (kind === "ping") return;
    let data: unknown = dataLine ? dataLine.slice(6) : null;
    try { data = JSON.parse(String(data)); } catch { /* data brut */ }
    handlers.onEvent({ kind, ...(typeof data === "object" && data ? data : {}) });
    if (kind === "done" || kind === "error" || kind === "cancelled") handlers.onDone();
  };
  while (true) {
    const { done, value } = await reader.read();
    if (done) return;
    buffer += decoder.decode(value, { stream: true });
    let idx: number;
    while ((idx = buffer.indexOf("\n\n")) !== -1) {
      handle(buffer.slice(0, idx));
      buffer = buffer.slice(idx + 2);
    }
  }
}
```

```ts
export function toCsv(rows: { id: number; url: string; title: string }[]): string {
  const esc = (s: string) => (/[",;\n]/.test(s) ? `"${s.replaceAll('"', '""')}"` : s);
  const lines = rows.map((r) => [r.id, r.url, r.title].map((v) => esc(String(v))).join(";"));
  return ["id;url;titre", ...lines].join("\n");
}

export function downloadCsv(filename: string, csv: string): void {
  const blob = new Blob([`﻿${csv}`], { type: "text/csv;charset=utf-8" });
  const a = document.createElement("a");
  a.href = URL.createObjectURL(blob);
  a.download = filename;
  a.click();
  URL.revokeObjectURL(a.href);
}
```

```tsx
export function ReviewPage({ review, goBack }: { review: ReviewView; goBack(): void }) {
```

```tsx
import userEvent from "@testing-library/user-event";
import { QueryClientProvider, QueryClient } from "@tanstack/react-query";
import type { ReactNode } from "react";
import { Banners } from "./Banners";

vi.mock("../hooks/useStaticData", () => ({
  useHealth: () => ({ data: { status: "ok", mcp: "crashed" }, refetch: vi.fn() }),
}));
const sendMock = vi.fn(async () => ({}));
vi.mock("../lib/api", () => ({ api: { send: sendMock } }));

const wrapper = ({ children }: { children: ReactNode }) => <QueryClientProvider client={new QueryClient()}>{children}</QueryClientProvider>;

describe("Banners", () => {
  it("mcp crashed → bannière + bouton redémarre (POST /api/mcp/restart)", async () => {
    render(<Banners />, { wrapper });
    expect(screen.getByText(/Connexion Raindrop interrompue/)).toBeInTheDocument();
    await userEvent.click(screen.getByRole("button", { name: /Redémarrer la connexion/ }));
    await waitFor(() => expect(sendMock).toHaveBeenCalledWith("POST", "/api/mcp/restart"));
  });
});
```
