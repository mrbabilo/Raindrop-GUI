# Raindrop GUI v0.1.0-pre.22

Préversion macOS Apple Silicon (arm64).

## Interface et animations

- Première passe de la charte UI v2 sur la bibliothèque avec fiche,
  Nettoyage et Revue.
- Titres et actions plus lisibles, recherche adaptable, cartes de nettoyage
  structurées et Revue utilisant toute la largeur disponible.
- Actions principales contrastées et contrôles communs portés à 32 px.
- Transitions courtes de 120 à 180 ms, indicateur de chargement accessible et
  suppression de toutes les animations lorsque macOS demande de réduire les
  mouvements.

## Doublons devenus introuvables

- L’ouverture d’un résultat périmé distingue désormais un HTTP 404 confirmé
  d’une panne réseau ou serveur. Le message ambigu du connecteur MCP n’est plus
  suffisant pour déclarer un signet absent.
- La fiche explique que le résultat d’analyse peut être périmé et propose
  « Actualiser les doublons ». L’analyse ne démarre qu’au clic, expose son état
  d’attente et ses erreurs, et ne supprime aucun signet automatiquement.
- Un 404 confirmé périme l’instantané partagé afin que l’analyse relise la
  bibliothèque au lieu de réutiliser le résultat ancien.

## Validation

- 1 275 tests Vitest réussis, 2 tests d’intégration ignorés.
- 80 tests navigateur sur Chromium et WebKit, en clair 1280 × 800 et sombre
  960 × 600, dont les parcours de résultat périmé et de mouvement réduit.
- Tests Rust, trois typechecks, builds front/sidecar, contrôle de taille et
  build natif complet exécutés pour cette version.
- Version du bundle, sidecar et MCP embarqués, signature ad-hoc, ZIP, DMG et
  empreintes SHA-256 contrôlés avant publication.

## Installation et limites

Télécharger le DMG ou décompresser le ZIP, puis copier **Raindrop GUI.app**
dans Applications. La signature est ad-hoc, sans Developer ID ni notarisation
Apple ; macOS peut bloquer le premier lancement.

Les tests navigateur utilisent une API simulée. La recette complète dans le
shell Tauri, VoiceOver et les actions sur des données Raindrop contrôlées restent
suivies dans la roadmap.
