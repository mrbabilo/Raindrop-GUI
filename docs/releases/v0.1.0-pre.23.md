# Raindrop GUI v0.1.0-pre.23

Préversion macOS Apple Silicon (arm64).

## Sélection et survols

- Maintenir le bouton principal sur une case puis traverser les suivantes
  sélectionne ou désélectionne toute la série.
- Le geste fonctionne dans la bibliothèque, les collections, le Nettoyage,
  les groupes de doublons et la Revue.
- Le clic simple, Maj-clic, le clavier, le tactile et la protection du dernier
  exemplaire d’un groupe de doublons restent disponibles.
- Les cases et les lignes partagent des transitions de survol courtes, coupées
  lorsque macOS demande de réduire les mouvements.

## Diagnostics plus lisibles

- Une chaîne rompue identifie les liens invalides, une flèche les redirections,
  un point d’interrogation les résultats à vérifier et deux copies les doublons.
- Ces pictogrammes complètent les filets existants dans le tableau de bord
  Nettoyage, ses résultats, la liste et la mosaïque.
- Les icônes isolées portent un nom accessible. Les cartes déjà libellées
  évitent une annonce redondante.
- Un résultat indéterminé avec URL finale conserve désormais sa marque « à
  vérifier » au lieu de reprendre celle d’une redirection.

## Validation

- 1 282 tests Vitest réussis, 2 tests d’intégration ignorés.
- 88 tests navigateur réussis sur Chromium et WebKit, en clair 1280 × 800 et
  sombre 960 × 600.
- 73 tests Rust réussis, 2 tests dépendant de la machine ignorés.
- Trois typechecks, build front, contrôle de taille et build natif complet
  réussis.
- Version du bundle, sidecar et MCP embarqués, signature ad hoc, ZIP, DMG et
  empreintes SHA-256 contrôlés avant publication.

## Installation et limites

Télécharger le DMG ou décompresser le ZIP, puis copier **Raindrop GUI.app**
dans Applications. La signature est ad hoc, sans Developer ID ni notarisation
Apple ; macOS peut bloquer le premier lancement.

Les tests navigateur utilisent une API simulée. La recette complète dans le
shell Tauri, VoiceOver et les actions sur des données Raindrop contrôlées restent
suivies dans la roadmap.
