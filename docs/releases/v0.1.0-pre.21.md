# Raindrop GUI v0.1.0-pre.21

Préversion macOS Apple Silicon (arm64).

## Nouveautés et corrections

- Intégration des améliorations de fiabilité, UX et ergonomie depuis pre.20 : persistance du cache d’analyse sérialisée, erreurs explicites, édition des étiquettes et collections, historique de navigation, nouveaux raccourcis et fiche redimensionnable.
- Conservation du nouveau brouillon quand une création précédente se termine.
- Verrouillage synchrone de toute l’exécution de Revue, dont les suppressions de collections.
- Réglages : focus initial et confiné, retour au déclencheur, Échap sans fermer la fiche sous-jacente. ⌘R ne recharge pas la fenêtre pendant une modale.
- Palette : l’option active reste visible pendant la navigation au clavier.
- Ajout de tests navigateur pilotables, de l’audit et d’une roadmap réconciliée avec la branche GitHub.

## Validation

- 52 tests UI sur Chromium et WebKit, thèmes clair/sombre, fenêtres 1280×800 et 960×600.
- 1 263 tests Vitest réussis, 2 tests d’intégration ignorés faute de compte de test explicite.
- 73 tests Rust réussis, 2 ignorés.
- Typechecks, builds front/sidecar et contrôle de taille vérifiés.
- Le harnais UI simule les réponses HTTP : il ne valide pas un compte Raindrop réel ni tous les comportements natifs de WKWebView.

## Installation et limites

Télécharger le DMG ou décompresser le ZIP, puis copier **Raindrop GUI.app** dans Applications.
La signature est ad-hoc, sans Developer ID ni notarisation Apple, comme les préversions précédentes ; macOS peut bloquer le premier lancement.

La charte UI v2 reste une proposition. Les points d’audit non résolus et les vérifications natives restantes sont suivis dans `docs/ROADMAP.md`. Cette préversion ne constitue pas une clôture de l’audit complet.
